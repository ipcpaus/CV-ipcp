# CV Profesional
**Ingrid Paulina Castillo Pérez**  

Currículum vitae en formato web desarrollado para presentar de forma clara e interactiva mi experiencia profesional, formación académica, certificaciones y competencias técnicas.

Mi perfil está orientado principalmente a **Soporte Técnico, Operación de TI y Tecnologías de la Información**, complementado con experiencia en análisis y gestión de datos.

Ver CV en línea: https://ipcpaus.github.io/CV-ipcp/

Este proyecto presenta una versión digital e interactiva de mi currículum, facilitando la consulta de mi trayectoria profesional desde cualquier dispositivo.

El sitio incluye:

- Experiencia profesional.
- Formación académica.
- Cursos y certificaciones.
- Competencias técnicas y profesionales.
- Herramientas y tecnologías utilizadas.
- Conocimientos en redes y telecomunicaciones.
- Opción para descargar el CV.
- Diseño adaptable para computadoras y dispositivos móviles.

**Áreas de experiencia**

- Soporte técnico y atención a usuarios.
- Operación y administración de TI.
- Gestión de incidencias.
- Administración de usuarios, accesos y equipos.
- Gestión de activos tecnológicos.
- Microsoft 365 y plataformas corporativas.
- Análisis y gestión de información.
- Redes y telecomunicaciones.
